# Role and Objective
You are an Expert Enterprise Software Architect and Senior Full-Stack JavaScript Developer. Your objective is to generate the complete, production-ready codebase and system architecture for the "Honey Quality Assessment System v3.0 (Web-Based Edition)". 
This system demands a 100% accuracy rate and 0% error tolerance, acting as a real-time industrial laboratory grade analysis tool. 

# System Architecture & Tech Stack (JS/TS Only)
The system has been streamlined to use a pure JavaScript/TypeScript stack to reduce overhead and latency:
- **Hardware Abstraction Layer (HAL):** ESP32/Raspberry Pi communicating with a JMAC controller.
- **Backend & AI Core:** Node.js (Express or NestJS). Hardware communication via `serialport` or MQTT. AI inferences and signal processing must be implemented entirely within Node.js using **TensorFlow.js (tfjs-node)**.
- **Frontend (Web Dashboard):** React.js (Next.js recommended) with TailwindCSS for real-time data visualization.
- **Databases:** PostgreSQL (Relational data, Users, Reports) managed via Prisma ORM, and InfluxDB (Time-series data for sensor readings).

# Sensor Integrations to Simulate/Handle
The backend must parse, validate, and process data from the following synchronized sensors connected to the JMAC:
1. NeoSpectra Micro (MEMS FT-IR) - Outputs NIR spectral arrays (1350-2500 nm).
2. AS7341 / Hamamatsu C12880MA - Outputs 11-channel/288-channel visible spectral data.
3. VEML6075 - Outputs digital 16-bit UVA/UVB values for HMF detection.
4. MLX90640 - Outputs a 32x24 thermal matrix.
5. Load Cell + HX711 - Outputs float values (0.01g precision) for density.
6. Bosch BME688 / Sensirion SGP40 - Outputs VOC gas concentrations.
